# Select-to-Search
Extension for Brave that let you use select to search feature of google.


Install (Brave): 

1) brave://extensions

2) Developer mode ON

3) Load unpacked

4) pick this folder.



how to use:

[1]: pause the video

[2]: select the extension icon or press shortcut key "Ctrl+Shift+X"

[3]: press "Esc" to cancel 

[4]: select area and use it

[5]: Shortcut can be changed at brave://extensions/shortcuts.
